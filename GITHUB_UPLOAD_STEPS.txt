GitHub 上傳步驟

資料夾：
C:\Users\USER\Downloads\AI AGENTS\Username-OSINT-Linker

一、先設定 Git 身分

git config user.name "你的 GitHub 名稱"
git config user.email "你的 GitHub email"

二、建立第一個 commit

git add .
git commit -m "Initial release of Username OSINT Linker"

三、到 GitHub 建立公開 repo

建議 repo 名稱：
Username-OSINT-Linker

四、連到遠端 repo

git branch -M main
git remote add origin https://github.com/你的帳號/Username-OSINT-Linker.git
git push -u origin main

五、建議開兩個 issue

Issue 1:
Improve public profile metadata extraction

Issue 2:
Add unit tests for account linkage scoring
